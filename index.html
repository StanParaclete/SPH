Installing on Windows

  1. Open the file you downloaded, SP-H_Felchris_Setup_1.2.106.exe.
  2. If you see "Windows protected your PC", click More info, then Run anyway. This appears because the installer is not yet registered with Microsoft. It is safe.
  3. Follow the installer. SP-H appears in the Start menu and on the desktop.

Installing on Mac

  1. Open the downloaded file and drag Stan Paraclete Hospital Hub into Applications.
  2. Open it from Applications. If macOS says it can't check the app, open System Settings → Privacy & Security, scroll down and click Open Anyway. You only do this once.

Already using SP-H?

Make a backup of your clinic's data in SP-H before installing a new version, then install over the top. Your patients and records stay where they are.
